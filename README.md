# Life-Hack-Urban-Myth
Life Hack or Urban Myth? is an interactive Android quiz application developed using Kotlin. The purpose of the app is to test users’ knowledge of common life hacks, everyday facts, and popular myths.

Users are presented with a series of statements and must decide whether each statement is a useful life hack or an urban myth. The application provides feedback on their answers, keeps track of their score, and displays their final results at the end of the quiz.

The app aims to make learning fun, improve critical thinking, and encourage users to question common beliefs. It features a simple, user-friendly interface that allows users to start the quiz, answer questions, view their scores, and play again.




An Android quiz game built using Kotlin.

## Features
- Welcome screen
- Hack or Myth quiz questions
- Instant feedback
- Score calculation
- Results screen
- Answer review
